# The Goodus Boy M.Salim — বাংলা অনলাইন প্রশ্নব্যাংক

## কী আছে
- নবম–দশম শ্রেণির জন্য responsive বাংলা ওয়েবসাইট
- বিষয়/অধ্যায় খোঁজার সুবিধা
- MCQ পরীক্ষা ও তাৎক্ষণিক স্কোর
- সংক্ষিপ্ত প্রশ্নের নমুনা উত্তর
- সৃজনশীল প্রশ্নের লিখিত উত্তর অনুশীলন
- কোনো লগইন বা ডেটাবেসের দরকার নেই

## GitHub-এ বর্তমান সাইট আপডেট
1. ZIP ফাইলটি Extract করুন।
2. GitHub-এ আপনার `Bangla-quiz-` repository খুলুন।
3. `Add file` → `Upload files` নির্বাচন করুন।
4. এই ফোল্ডারের `index.html`, `style.css`, `script.js`, `questions.js`, `README.md` ফাইলগুলো আপলোড করুন। `.github` ফোল্ডারটি মুছবেন না।
5. `Commit changes` চাপুন। একই নামে ফাইল থাকলে GitHub replace/update করবে।
6. Settings → Pages-এ Branch `main`, folder `/(root)` আছে কি না নিশ্চিত করুন।

## নতুন প্রশ্ন যোগ করা
`questions.js` ফাইল সম্পাদনা করুন। প্রতিটি বিষয়ের `chapters` তালিকায় নতুন অধ্যায় যোগ করুন। একটি অধ্যায়ে `mcq`, `short`, `creative`—যেকোনো তালিকা থাকতে পারে।

MCQ নমুনা:
```js
{q:"প্রশ্নটি এখানে", options:["বিকল্প ক","বিকল্প খ","বিকল্প গ","বিকল্প ঘ"], answer:0, explanation:"উত্তরের ব্যাখ্যা"}
```
`answer` হলো সঠিক বিকল্পের শূন্য-ভিত্তিক index: 0=প্রথম, 1=দ্বিতীয়, 2=তৃতীয়, 3=চতুর্থ।

সংক্ষিপ্ত প্রশ্ন:
```js
{q:"সংক্ষিপ্ত প্রশ্নটি এখানে", sample:"নমুনা উত্তর এখানে"}
```

সৃজনশীল প্রশ্ন:
```js
{stem:"উদ্দীপক এখানে", parts:[["ক","প্রথম অংশ"],["খ","দ্বিতীয় অংশ"],["গ","তৃতীয় অংশ"],["ঘ","চতুর্থ অংশ"]]}
```
