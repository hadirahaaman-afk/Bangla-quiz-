# The Goodus Boy M.Salim — SSC Practice Website

বাংলাদেশের নবম–দশম শ্রেণির SSC প্রস্তুতির জন্য একটি GitHub Pages ওয়েবসাইটের প্রাথমিক সংস্করণ।

## এই সংস্করণে
- ১২টি বই/বিষয়ের আলাদা সেকশন ও অধ্যায় তালিকা
- পদার্থবিজ্ঞানের ১৪টি অধ্যায়ে মোট ৭০টি স্থানীয় MCQ অনুশীলন, উত্তর ও ব্যাখ্যা
- অধ্যায়ভিত্তিক MCQ পরীক্ষা, পুরো পদার্থবিজ্ঞান বইয়ের MCQ মডেল টেস্ট, ফলাফল ও উত্তর পর্যালোচনা
- অন্যান্য বইয়ের অধ্যায়-সেকশনও এখন থেকেই দৃশ্যমান; যেসব অধ্যায়ের প্রশ্ন নেই সেখানে তা স্পষ্ট করে বলা হয়
- সংক্ষিপ্ত ও সৃজনশীল প্রশ্নের জায়গা প্রস্তুত; বইয়ের পৃষ্ঠা/প্রশ্নের ছবি থেকে ধাপে ধাপে যোগ করা যাবে

## গুরুত্বপূর্ণ
- পদার্থবিজ্ঞানের বর্তমান ৭০টি MCQ অনুশীলনের জন্য তৈরি; এগুলোকে ২০১৫–২০২৬ সালের আসল বোর্ড প্রশ্ন বলে দাবি করা হচ্ছে না।
- ১২টি বইয়ের তালিকা ও অধ্যায়ের নাম প্রাথমিক খসড়া। শিক্ষার্থীর ব্যবহৃত NCTB বই/বোর্ড/বিভাগের সূচিপত্রের ছবি পেলে নাম ও অধ্যায়গুলো ঠিক বইয়ের সঙ্গে মিলিয়ে সংশোধন করতে হবে।
- নতুন প্রশ্ন যোগ করতে `questions.js`-এর সংশ্লিষ্ট বইয়ের অধ্যায়ে `mcq`, `short`, এবং `creative` অ্যারেতে প্রশ্ন যোগ করা হয়।

## GitHub Pages-এ আপডেট
1. ZIP Extract করো।
2. `index.html`, `style.css`, `script.js`, `questions.js`, `README.md` repository-র root-এ upload করে পুরোনো ফাইল replace করো।
3. Commit changes করো। GitHub Pages branch/folder আগের মতো `main` / root-এ রাখো।
