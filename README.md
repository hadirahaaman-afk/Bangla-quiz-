# The Goodus Boy M.Salim — পদার্থবিজ্ঞান প্রশ্নব্যাংক

## এই সংস্করণে
- নবম–দশম শ্রেণির পদার্থবিজ্ঞানের ১৪টি অধ্যায়
- প্রতিটি অধ্যায়ে ধারণাভিত্তিক MCQ, স্বয়ংক্রিয় নম্বর ও ব্যাখ্যা
- অধ্যায়ভিত্তিক সংক্ষিপ্ত প্রশ্নের নমুনা উত্তর
- বিগত বছরের প্রশ্ন যাচাই করার জন্য বাহ্যিক সংগ্রহের লিংক

## গুরুত্বপূর্ণ
বর্তমান MCQ-গুলো অনুশীলনী হিসেবে তৈরি; এগুলোকে ২০১৫–২০২৬ সালের আসল বোর্ড প্রশ্ন বলে দাবি করা হচ্ছে না। বোর্ড প্রশ্ন যোগ করার সময় প্রশ্নপত্রের সাল, বোর্ড এবং উৎস যাচাই করে আলাদা করে চিহ্নিত করতে হবে। এই সংস্করণটি সম্পূর্ণ বোর্ড-প্রশ্ন আর্কাইভ নয়; এটি সব অধ্যায় চালু করা প্রথম ভিত্তি সংস্করণ।

## GitHub Pages-এ আপডেট
1. ZIP ফাইলটি extract করো।
2. GitHub repository-তে `index.html`, `style.css`, `script.js`, `questions.js`, `README.md` ফাইলগুলো upload করে পুরোনো ফাইল replace করো।
3. Commit changes করো।
4. GitHub Pages-এর Settings → Pages-এ `main` branch এবং `/(root)` নির্বাচিত আছে কি না দেখো।
5. ওয়েবসাইটে পুরোনো পেজ এলে browser refresh করো বা কয়েক মিনিট অপেক্ষা করো।
